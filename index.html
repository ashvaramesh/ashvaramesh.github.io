ImpactLink

ImpactLink is a community-focused app connecting high school and college students with volunteer, internship, and civic engagement opportunities. Designed to track impact through logged hours, badges, and achievements, it encourages users to actively participate in community service.

Overview

Setup Instructions:
1. Clone the Repository: git clone https://github.com/ashvaramesh/swift-project
2. Install Dependencies: Open the project in Xcode, go to File > Swift Packages > Add Package Dependency, and add Firebase’s GitHub link.
3. Configure Firebase: Set up a Firebase project, add your app, and download GoogleService-Info.plist to the project root.

Feature Overview:
- Opportunity Tracking: Log volunteer hours, view stats, track achievements
- Starred Activities: Bookmark specific opportunities and manage them in the journal
- Profile Customization: Add skills, set goals, choose avatars
- Gamification: Earn badges and appear on leaderboards
- Dynamic Filters: Browse by volunteer, government, environmental categories, and more
- Accessibility: Screen reader and dark mode support

Usage Instructions:
1. Onboarding: Complete initial onboarding to set interests, pick an avatar, and get a quick tour
2. Main Navigation: Access Home for opportunities, Profile for personal achievements, and Leaderboard for top volunteers
3. Logging Hours: Use the Volunteer Tracker to add time and reflect in the journal
4. Creating Events: Add new volunteer events in the Create Event section

Future Enhancements:
- Real-Time Firebase Updates for immediate feedback across users
- Expanded Accessibility for improved navigation with screen readers

ImpactLink Extended Project

A dynamic iOS application initially built with full online features, now adapted for offline-first usage (for the Apple WWDC Swift Student Challenge). Seamless merging of offline and online modes is planned for a comprehensive user experience.

Research & Planning Documentation

In the early stages, ImpactLink was powered heavily by Firebase for user authentication, real-time volunteer tracking, and event management. However, Apple’s WWDC Swift Student Challenge rules prompted a shift to offline data storage for Swift Playgrounds compatibility.

User feedback, community surveys, and competitor analyses helped us refine essential features like category tagging, star toggling, and integrated journals. We’ve documented these findings in a series of design sprints, culminating in a clear plan to integrate both offline resilience and online collaboration features after the challenge deadline.

Current Progress

  • Offline Data Persistence: Finalized local storage system using Swift structures, ensuring volunteer hours and event logs remain available without an internet connection.
  • Refined UI: Introduced a consistent color scheme, a cleaner layout for the Journal screen, and improved animations when toggling star/favorite icons.
  • Performance Improvements: Profile loading times are now 50% faster after optimizing image caching and data retrieval methods.
  • Accessibility Features: Enhanced VoiceOver support for visually impaired users and introduced larger font scaling options for better readability.
  • Testing & Feedback: Conducted multiple user tests to gather input on the offline version’s reliability, resulting in an improved local caching strategy.

Code Snippets

Below is a key SwiftUI structure that dynamically renders volunteer or internship opportunities. This snippet demonstrates how categories are color-tagged, how a star icon toggles between saved and unsaved states, and how the entire view animates when it appears.

We use @EnvironmentObject to access the shared OpportunityViewModel, which manages the global state for all opportunities. This approach ensures that when a user taps the star button, the corresponding opportunity is updated instantly throughout the app. 

// MARK: - Opportunity Card View
struct OpportunityCardView: View {
    @EnvironmentObject var viewModel: OpportunityViewModel
    let opportunity: Opportunity
    @State private var animate = false

    func colorForCategory(_ category: Category) -> Color {
        switch category {
        case .volunteer:      return .volunteerTag
        case .government:     return .governmentTag
        case .competition:    return .competitionTag
        case .science:        return .scienceTag
        case .internship:     return .internshipTag
        case .education:      return .educationTag
        case .environmental:  return .environmentalTag
        case .healthcare:     return .healthcareTag
        case .communityService:return .communityServiceTag
        case .artsCulture:    return .artsCultureTag
        case .technology:     return .technologyTag
        case .advocacy:       return .advocacyTag
        case .leadership:     return .leadershipTag
        case .math:           return .mathTag
        case .engineering:    return .engineeringTag
        }
    }

    var body: some View {
        VStack(alignment: .leading, spacing: 10) {
            HStack(alignment: .top, spacing: 15) {
                Image(systemName: opportunity.imageName)
                    .resizable()
                    .scaledToFit()
                    .frame(width: 50, height: 50)
                    .foregroundColor(.accentColor)
                    .padding()
                    .background(
                        RoundedRectangle(cornerRadius: 15)
                            .fill(Color.cardBackgroundColor)
                            .shadow(color: Color.black.opacity(0.1), radius: 5, x: 0, y: 5)
                    )
                    .scaleEffect(animate ? 1.0 : 0.8)
                    .opacity(animate ? 1.0 : 0.5)
                    .animation(.easeOut(duration: 0.5).delay(0.2), value: animate)

                VStack(alignment: .leading, spacing: 5) {
                    Text(opportunity.title)
                        .font(.headline)
                        .foregroundColor(.primaryColor)
                    HStack {
                        ForEach(opportunity.categories, id: \.self) { category in
                            Text(category.rawValue)
                                .font(.caption)
                                .padding(.vertical, 4)
                                .padding(.horizontal, 8)
                                .background(colorForCategory(category))
                                .foregroundColor(.white)
                                .cornerRadius(10)
                        }
                    }
                }

                Spacer()

                Button(action: {
                    withAnimation { viewModel.toggleStar(for: opportunity) }
                }) {
                    Image(systemName: opportunity.isStarred ? "star.fill" : "star")
                        .foregroundColor(opportunity.isStarred ? .yellow : .gray)
                        .scaleEffect(opportunity.isStarred ? 1.2 : 1.0)
                        .animation(.easeInOut(duration: 0.2), value: opportunity.isStarred)
                }
            }
        }
        .padding()
        .background(
            RoundedRectangle(cornerRadius: 20)
                .fill(Color.cardBackgroundColor)
                .shadow(color: Color.black.opacity(0.1), radius: 5, x: 0, y: 5)
        )
        .onAppear { animate = true }
    }
}
